# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer works using the IPOS (Input, Processing, Output, Storage) cycle, identify real hardware and software items used on a MacBook, and describe three everyday computer-based systems outside of laptops and mobile phones.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS
**Chosen activity:** Writing and saving a note using Apple Notes.

| Stage | What happens in your example? | Hardware / component involved |
| --- | --- | --- |
| Input | Typed a sentence using the MacBook's built-in keyboard. | Built-in keyboard |
| Processing | The processor and memory handled the keystrokes inside the Apple Notes app and prepared the text to be shown and saved. | CPU (processor) and memory (RAM) |
| Output | The typed sentence appeared on the MacBook screen. | Built-in display (screen) |
| Storage | After closing and reopening Apple Notes, the sentence remained saved in Apple Notes. | Persistent storage (used by Apple Notes) |

**How the activity moves from input to output and storage:**
When I press keys on the built-in keyboard, the computer receives those key presses as input. The CPU and memory process the input inside Apple Notes and immediately send the text as output to the display so I can read what I typed. At the same time, Apple Notes keeps the note in persistent storage, which is why the sentence remained saved in Apple Notes after I closed and reopened the app.

## 4. My understanding
- **IPOS cycle:** Every task on a computer follows Input, Processing, Output, and Storage. Even a simple action like writing a note involves hardware (keyboard, CPU/RAM, display, persistent storage) and software (macOS and Notes) working together.
- **Hardware vs. software:** Hardware consists of the physical parts we can touch, while software consists of the programs that run on that hardware. Operating systems manage the computer, applications help users complete tasks, and utilities help inspect, maintain, and manage the system.
- **Computers beyond laptops and phones:** Devices like ATMs, traffic signals, and ticket machines are also computer systems because they take input, process it according to rules, and produce useful output in daily life.
