# The Digital Detective (`digital-detective-8552`)

A beginner-friendly, hands-on mini system report exploring how a computer works—from basic hardware and the Terminal to operating systems, Python programs, number systems, Git/GitHub workflows, and computer networks.

## How This Repository Is Organised
Each mission (Mission 0 through Mission 8) is completed in order, documented in its own `README.md`, and saved as a separate Git commit and push to GitHub before moving on to the next mission.
